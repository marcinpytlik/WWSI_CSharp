# LinqDotnet9Challenges (.NET 9)

30 mini-projektów (zadania 1–30) jako osobne biblioteki + osobne projekty testów xUnit (Moq tam gdzie trzeba).

## Komendy
```powershell
dotnet restore
dotnet build
dotnet test
```

## Struktura
- `src/TaskXX_*` – implementacja zadania
- `tests/TaskXX_*.Tests` – testy jednostkowe
