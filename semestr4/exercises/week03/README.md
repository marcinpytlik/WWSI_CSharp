# Tydzień 3 – Składnia zapytaniowa vs metodowa

**Maksymalna liczba punktów: 100 pkt**

Ćwiczenia wykonuj w .NET 10. Tam, gdzie ma to sens, rozdziel logikę od wejścia/wyjścia i dbaj o czytelne nazwy.

## Ćwiczenie 1. To samo zapytanie dwa razy — 10 pkt

Zapisz filtrowanie i sortowanie listy osób w query syntax i method syntax.

**Kryteria zaliczenia:**

- Dwie równoważne wersje.

- ten sam wynik.

- czytelność.

## Ćwiczenie 2. Query z let — 15 pkt

Użyj let do wyliczenia wartości pośredniej w zapytaniu, np. ceny brutto.

**Kryteria zaliczenia:**

- query syntax.

- let.

- poprawna projekcja.

## Ćwiczenie 3. Query join — 20 pkt

Napisz join w składni zapytaniowej oraz jego odpowiednik metodowy.

**Kryteria zaliczenia:**

- 2 wersje join.

- równoważność.

- dobre nazwy.

## Ćwiczenie 4. Deferred execution — 25 pkt

Pokaż eksperyment demonstrujący deferred execution i materializację ToList.

**Kryteria zaliczenia:**

- Zmiana kolekcji między definicją a enumeracją.

- komentarz.

- ToList.

## Ćwiczenie 5. Benchmark czytelności — 30 pkt

Przygotuj trzy złożone zapytania i uzasadnij, dla których wybierasz składnię query, a dla których method.

**Kryteria zaliczenia:**

- 3 zapytania.

- obie składnie.

- techniczne uzasadnienie.

- brak zmiany wyniku.
