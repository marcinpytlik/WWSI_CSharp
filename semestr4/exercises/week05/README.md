# Tydzień 5 – JSON i XML

**Maksymalna liczba punktów: 100 pkt**

Ćwiczenia wykonuj w .NET 10. Tam, gdzie ma to sens, rozdziel logikę od wejścia/wyjścia i dbaj o czytelne nazwy.

## Ćwiczenie 1. Serializacja JSON — 10 pkt

Zserializuj listę obiektów do JSON z formatowaniem i zapisz do pliku.

**Kryteria zaliczenia:**

- System.Text.Json.

- WriteIndented.

- zapis pliku.

## Ćwiczenie 2. Deserializacja JSON — 15 pkt

Wczytaj JSON i odtwórz obiekty; obsłuż brakujące/błędne dane.

**Kryteria zaliczenia:**

- Deserialize.

- walidacja null.

- JsonException.

## Ćwiczenie 3. XML podstawy — 20 pkt

Zapisz i odczytaj listę obiektów w XML.

**Kryteria zaliczenia:**

- Poprawny XML.

- round-trip.

- typowany model.

## Ćwiczenie 4. Konwersja JSON→XML — 25 pkt

Wczytaj dane JSON i wygeneruj równoważny dokument XML.

**Kryteria zaliczenia:**

- Dwa formaty.

- mapowanie.

- zachowanie danych.

## Ćwiczenie 5. Konfiguracja aplikacji — 30 pkt

Zaprojektuj klasę AppSettings wczytywaną z JSON, walidowaną i używaną przez aplikację; dodaj sensowne wartości domyślne.

**Kryteria zaliczenia:**

- Model ustawień.

- walidacja.

- fallback.

- obsługa błędnego pliku.

---

**Suma: 100 pkt**
