# Tydzień 1 – Wprowadzenie do .NET i C#

**Maksymalna liczba punktów: 100 pkt**

Ćwiczenia wykonuj w .NET 10. Tam, gdzie ma to sens, rozdziel logikę od wejścia/wyjścia i dbaj o czytelne nazwy.

## Ćwiczenie 1. Pierwsza aplikacja konsolowa — 10 pkt

Utwórz aplikację konsolową .NET 10, która wyświetli imię, kierunek studiów i aktualną wersję środowiska uruchomieniowego.

**Kryteria zaliczenia:**

- Poprawne uruchomienie projektu.

- czytelny kod.

- co najmniej 3 informacje w wyniku.

## Ćwiczenie 2. Kalkulator danych wejściowych — 15 pkt

Pobierz od użytkownika dwie liczby i wyświetl ich sumę, różnicę, iloczyn i iloraz. Zabezpiecz dzielenie przez zero.

**Kryteria zaliczenia:**

- Wczytywanie danych.

- cztery operacje.

- komunikat dla dzielenia przez zero.

## Ćwiczenie 3. Formatowanie danych — 20 pkt

Pobierz imię, nazwisko, rok urodzenia i wzrost. Wyświetl dane używając interpolacji, formatowania liczb oraz poprawnie obliczonego wieku.

**Kryteria zaliczenia:**

- Interpolacja.

- format liczbowy.

- poprawne obliczenia.

## Ćwiczenie 4. Mini wizytówka CLI — 25 pkt

Zbuduj prostą wizytówkę tekstową z nagłówkiem, separatorami i danymi użytkownika. Program ma używać co najmniej jednej stałej i jednej zmiennej lokalnej.

**Kryteria zaliczenia:**

- Czytelny układ.

- użycie const.

- poprawne nazewnictwo zmiennych.

## Ćwiczenie 5. Analizator środowiska — 30 pkt

Napisz program, który pokaże wersję .NET, system operacyjny, liczbę procesorów logicznych i katalog bieżący. Dodaj krótkie objaśnienie każdej wartości.

**Kryteria zaliczenia:**

- Użycie API środowiska.

- komplet danych.

- komentarz/objaśnienie wyniku.

---

**Suma: 100 pkt**
