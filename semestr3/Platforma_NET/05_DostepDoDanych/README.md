# 05 — .NET i dane

Wykorzystaj istniejącą [demonstrację 08 — Biblioteka EF](../../../demonstracje/08_BibliotekaEf/README.md), która używa EF Core i SQLite.

1. Pokaż encje i `DbContext`.
2. Wskaż zapytanie LINQ i miejsce, w którym EF Core wykonuje zapytanie do bazy.
3. Jeśli demonstracja już loguje SQL — pokaż log; jeśli nie, zatrzymaj się na omówieniu providera i kodu, nie twierdź, że widziałeś wygenerowany SQL.
4. Opcjonalnie skorzystaj z [demonstracji 12 — SQL Server least privilege](../../../demonstracje/12_EfCoreSqlLeastPrivilege/README.md), jeśli SQL Server jest przygotowany.

**Pytanie:** Czy LINQ zawsze oznacza SQL? Czym różni się biblioteka EF Core od silnika SQL Server?

Pokaz ma dotyczyć możliwości integracji; pełne mapowanie, migracje i transakcje zostają w semestrze 5.
