# Lab11 Projekt CLI — szczegółowe laboratorium

**Czas:** 120 min · mini-projekt zaliczeniowy

## Cel

Oddać mały program konsolowy z testami, jak `Lab01_Wprowadzenie`, ale z własną dziedziną.

## Zakres (wybierz jeden)

- **A.** Kalkulator: `add/sub/mul/div` + historia operacji
- **B.** Książka adresowa: `add/list/find` w pamięci
- **C.** Todo: `add/done/list` (bez pliku — plik to semestr 4)

## Wymagania

- `Program` cienki; logika w klasach
- `--help`, kody wyjścia
- min. 10 testów xUnit
- README: jak uruchomić 3 przykładowe komendy

## Kryteria zaliczenia projektu

- [ ] działa bez debugger-only magii
- [ ] testy nie kręcą prawdziwej konsoli
- [ ] nazwy po polsku **albo** po angielsku — spójnie
