# Dziennik ocen — tylko lokalnie

Szablony pustych arkuszy są w `templates/`. Skopiuj je poza git albo do
`Gradebook/local/` (katalog jest w `.gitignore`).

```bash
mkdir -p Gradebook/local
cp Gradebook/templates/semestr3.csv Gradebook/local/semestr3.csv
```

Nie commituj imion, nazwisk ani punktów studentów. Repo jest publiczne.
