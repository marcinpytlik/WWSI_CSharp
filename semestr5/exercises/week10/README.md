# Tydzień 10 – Projekt Users + Tasks API

**Maksymalna liczba punktów: 100 pkt**

Ćwiczenia wykonuj w .NET 10. Tam, gdzie ma to sens, rozdziel logikę od wejścia/wyjścia i dbaj o czytelne nazwy.

## Ćwiczenie 1. Model domeny — 10 pkt

Zaprojektuj User, TaskItem i Tag oraz DTO i relacje EF Core.

**Kryteria zaliczenia:**

- Encje.

- DTO.

- relacje.

- migracja.

## Ćwiczenie 2. CRUD API — 15 pkt

Zaimplementuj CRUD użytkowników i zadań z async EF Core, paginacją i filtrowaniem.

**Kryteria zaliczenia:**

- CRUD.

- async.

- DTO.

- 404/400.

- pagination.

## Ćwiczenie 3. Security — 20 pkt

Dodaj rejestrację, login JWT i politykę: użytkownik zarządza własnymi zadaniami, admin wszystkimi.

**Kryteria zaliczenia:**

- JWT.

- ownership.

- admin policy.

- 401/403.

## Ćwiczenie 4. Raporty — 25 pkt

Dodaj endpointy raportowe: zadania per status, per user, top tags i zaległe zadania.

**Kryteria zaliczenia:**

- Min. 4 raporty.

- LINQ/EF.

- DTO.

- efektywne zapytania.

## Ćwiczenie 5. Projekt końcowy API — 30 pkt

Dostarcz kompletne API z migracjami, seedem dev, middleware błędów, structured logging, min. 20 testami integracyjnymi i README z uruchomieniem oraz opisem architektury.

**Kryteria zaliczenia:**

- Działające API.

- min. 20 testów.

- security.

- logging.

- README.

- brak sekretów.

- poprawna struktura rozwiązania.

---

**Suma: 100 pkt**
