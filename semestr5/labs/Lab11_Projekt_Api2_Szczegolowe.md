# Lab11 Projekt Users+Tasks (część 2)

**Czas:** 120–150 min

## Cel

Dokończyć zaliczenie: JWT + testy + prezentacja 5 min.

## Zakres

- register/login
- taski tylko dla `sub` / `nameid` z tokena (nie wolno czytać cudzych)
- min. 6 testów integracyjnych (401, 403/404 cudzy zasób, happy path)
- lista ograniczeń w README (co nie jest produkcją: brak refresh tokena, itd.)

## Prezentacja

1. Architektura (30 s)
2. Demo login + CRUD (2 min)
3. Jedna decyzja (SQLite vs SQL Server, DTO, testy) (1 min)

## Kryteria

- [ ] bez tokena nie przejdziesz do tasków
- [ ] nie ma sekretów w repo
